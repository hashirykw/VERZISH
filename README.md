# The Verzish.com 3.0 — website

Unisex gym · Plot # B-122, Block H, North Nazimabad, Karachi · Open 24 hours.

## Files
Everything sits flat in one folder — no subfolders. `index.html` links every file directly by name.
- `index.html` — the whole site (HTML, CSS and JS in one file)
- `hero.mp4` + `hero.webm` — the 48-second gym reel (hero), `studio.mp4` — studio reel
- `logo.png` / `logo.webp`, `favicon.png`, `apple-touch-icon.png` — Verzish Vol.3 logo
- `*.webp` — 30+ photos taken from the gym's own reels

## Deploy
Upload every file in this folder to the root of a GitHub repo, then import it on Vercel
(Framework preset: **Other**, no build command) or turn on GitHub Pages for the `main` branch.
